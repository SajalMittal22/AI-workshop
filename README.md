# ✈️ Flight Booking Chatbot

An interactive chatbot built using Flask that helps users book flights in a simple conversational way.

---

## 🚀 Features

✨ Book flights using chat  
🌍 Supports cities like Delhi, Mumbai, Chennai, Bangalore, Kolkata  
📅 Select travel date  
👥 Choose number of passengers  
💺 Select class (Economy, Business, First Class)  
💬 Simple chatbot interface  

---

## 🛠️ Tech Stack

- Python  
- Flask  
- HTML

## ⚙️ Setup & Run

### 1. Clone the repo
git clone https://github.com/SajalMittal22/AI-workshop.git  
cd AI-workshop  

### 2. Create virtual environment
python3 -m venv venv  

### 3. Install Flask
venv/bin/pip install flask  

### 4. Run project
venv/bin/python flightBooking.py  

### 5. Open in browser
http://127.0.0.1:5000
