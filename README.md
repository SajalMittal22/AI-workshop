# ✈️ Flight Booking Chatbot

A simple Flask-based chatbot that helps users book flights interactively.

## 🚀 Features
- Book flights using chat
- Supports cities like Delhi, Mumbai, Chennai, etc.
- Select travel date and passengers
- Choose class (Economy, Business, First)
- Simple and interactive UI

## 🛠️ Tech Stack
- Python
- Flask
- HTML

## ▶️ How to Run

```bash
python flightBooking.py
